# Atividades de Vetores em Java

Repositório desenvolvido para praticar lógica de programação e manipulação de vetores utilizando a linguagem Java.

## Atividade 1 — Estoque de uma papelaria

Exercício para trabalhar com vetores, acessando posições específicas e consultando a quantidade de elementos armazenados.

## Atividade 2 — Correção de uma nota

Exercício para praticar a consulta e a alteração de valores em um vetor de notas de estudantes.

## Tecnologias utilizadas

- Java
- Visual Studio Code
- Git
- GitHub
